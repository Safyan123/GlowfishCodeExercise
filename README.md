# Getting Started

>**Note**: Make sure you have completed the [React Native - Environment Setup](https://reactnative.dev/docs/environment-setup) instructions till "Creating a new application" step, before proceeding.

### Steps to run the Glowfish Code Exercise Application

- Install the node modules by run the following command in the project directory `npm install` or `yarn`

#### For iOS

- Install the pods, Hit the command in the project directory `npx pod-install` or navigate to iOS directory and hit this command `pod install`

- In the _root_ directory of your React Native project, Run the following command to start your _iOS_ app:

```bash
# using npm
npm run ios

```



#### For Android
- Open the android emulator from Android Studio AVD Manager if there is no emulator created please create it first also you can connect a device with debugging enabled.
- Now open the terminal and run the following command

```bash
# using npm
npm run android

```


## Start the Metro Server

To start Metro, run the following command from the _root_ of your React Native project:

```bash
# using npm
npm start

# OR using Yarn
yarn start
```


If everything is set up _correctly_, you should see your new app running in your _Android Emulator_ or _iOS Simulator_ shortly provided you have set up your emulator/simulator correctly.

This is one way to run your app — you can also run it directly from within Android Studio and Xcode respectively.
